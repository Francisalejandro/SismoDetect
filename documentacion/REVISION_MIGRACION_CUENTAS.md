### 3.1 `auth_user` no se crea

`AUTH_USER_MODEL = "cuentas.Usuario"` y `auth.User._meta.swapped = "cuentas.Usuario"`. Verificado en ejecución.

Django omite la creación física de modelos sustituidos: `CreateModel.database_forwards()` llama a `allow_migrate_model()`, que a su vez usa `Options.can_migrate()`. Ese método devuelve `False` cuando `self.swapped` está definido:

```python
# django/db/models/options.py
if self.proxy or self.swapped or not self.managed:
    return False
```

Comprobación empírica adicional con el SQL de `auth.0001`:

```text

CREATE TABLE "auth_group" (...)
CREATE TABLE "auth_group_permissions" (...)
Apariciones de "auth_user": 0
```

Por tanto, aunque `migrate --plan` muestre `auth.0001_initial → Create model User`, esa operación es solo de estado y no crea la tabla `auth_user`.
